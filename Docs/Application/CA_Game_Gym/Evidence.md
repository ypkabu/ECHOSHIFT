## Problem-solving evidence

### 1. Carry object deletion on Echo cleanup

- Problem: Actor破棄時にheld Batteryが失われ、reset整合性が崩れる。
- Cause: BatteryをActor hierarchyの子へparentingしていた。
- Decision: ownership/stateをBatteryへ残し、hierarchy外からCarry Socket poseだけを追従。
- Verification: disable/destroy release、single ownership、world reset、recorded pickup/insert tests。
- Evidence: `Docs/Phase1Validation.md`, `Phase1InteractionPlayModeTests.cs`。

### 2. Floating visual artifacts regenerated by Builder

- Problem: wall外周のcyan/orange bars、rails、supportsが空中へ浮いた。
- Cause: old coordinateのindependent lamp loopと、backingなしpartial wall/diagonal support selection。
- Decision: instance非表示ではなくgeneration sourceを削除・限定し、continuous backingへ接続。
- Verification: rerun後orphan 0、EditMode `94/94`、PlayMode `93/93`、P3完走、drift `0 m`。
- Evidence: `Docs/Phase4FloatingVisualAudit.md`, `38beb04`。

### 3. Production Builder reserialization

- Problem: Builderはexit 0でも、承認済みController/Volume/Prefab/Sceneのbytesが毎回変化。
- Cause:同値assetのdirty/save、subasset再作成、visual child再生成、Scene全再作成によるlocal fileID再採番。
- Decision: approved exact SHA-256のcanonical guard。match時safe no-op、mismatch/partial missing時write前fail-closed。
- Verification: same-process/cross-process各3 runでdiff 0、isolated mismatch rejection、151/151・131/131再検証。
- Evidence: `Docs/Phase5ABuilderDeterminismFix.md`, `35bc519`, `d471010`, `1245b8a`。

### 4. Camera/HUD readability after playtesting

- Problem: Actor切れ、大きなHUD、Player/Echo識別不足。
- Cause: player-only framing、persistent objective/prompt、color中心のidentity。
- Decision: section bounds/look-ahead/group zoom、compact transient HUD、silhouette/marker generation差。
- Verification: five aspect/resolution camera/HUD tests、two-Echo projection tests、new captures、画面確認Pass。
- Evidence: `Docs/Phase4PresentationReadabilityValidation.md`, `910956a`, `e92736e`, `2757044`。

### 5. Windows graphical shutdown crash boundary

- Problem: normal gameplay後のvisible Windows Player終了で`0xC0000005`。
- Cause analysis: managed codeではなく`UnityPlayer.dll` native cleanup stackまでsymbolicate。URP Stage Bは1/5候補に留め、直接原因と断定しなかった。
- Result: safe graphical workaroundは未発見。release validationをblockedとして維持し、Bug Report用minimal repro/evidenceを分離。
- Evidence: `Docs/Phase4WindowsExitCrashInvestigation.md`, `Docs/UnityBugReport_WindowsPlayerExitCrash.md`, `4d0269e`。
