# CA Game Gym Submission Preparation Plan

## Objective

CA Game Gymの書類選考で、ECHO//SHIFTを根拠にUnity経験、Git経験、ゲームクライアント志向、課題解決力、主体性、チーム開発へ持ち込める基礎を短時間で確認できる状態にする。

## Scope

1. 公式募集要項とcurrent repository evidenceを照合する。
2. READMEを作品、技術、検証、AI-assisted development、既知制約が30秒で読める構成へ更新する。
3. Git経験、応募文案、evidence matrix、recruiter reviewを作成する。
4. 代表画像を生成済みProduction Captureから選び、追跡可能な応募用Mediaとして保存する。
5. Markdown link、Git diff、privacy、credential、license、generated artifactを監査する。
6. current HEADのUnity compile、EditMode、PlayMode、P3 regression evidenceを再確認する。

## Non-goals

- Gameplay、visual、audio、Scene、Prefab、Packageの変更。
- 新機能、新stage、大規模refactor、Steam integration。
- 共同開発、公開URL、release実績の創作。
- graphical Windows shutdown defectを隠したbuild配布。

## Evidence boundary

- 開発期間、commit数、branch、tagはGitから取得する。
- test数、drift、interaction結果はfresh XML/logまたはFormal Revalidationから取得する。
- Human Reviewとautomationを混同しない。
- AI/Codex支援を明記し、本人の具体的な担当範囲を推測しない。
- 学籍、卒業年、参加可否、所有PC、公開URLは本人未確認として残す。

## Completion gate

- Required application documents and README exist and have valid local links.
- Unity source/Scene/Prefab/Package diff is zero.
- EditMode and PlayMode pass on current HEAD.
- No root generated Build, Log, TestResults, Unity Library, credential, private absolute path, or unsupported claim is introduced.
- Remaining P0/P1/P2 items are explicit.
